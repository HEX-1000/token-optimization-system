# Contributing

- Bug reports: open an issue. Questions and ideas: use Discussions. Security problems: see `SECURITY.md`, not a public issue.
- Pull requests are read but not merged. This repository is built from a separate development repository, so an accepted change is re-applied there and appears here in the next version. A change to a file in `src\` also needs a new version and a new line in `SHA256SUMS`, so it cannot be a small edit.
- Do not include your documents, queries or index file in an issue or pull request; describe them instead.
- There is no promise about response time.
